## 第一大板块：理论基础

### 本课从哪个零基础问题开始

上一课知道 PPA 和 take-or-pay 可以提高供电确定性。今天继续问：

```text
一份未来十几年才逐步交付的购电合同，
为什么有时只是采购承诺，有时却要像衍生品一样每季重新估值？
```

关键不只在合同名称，而在合同条款：是否真正预期收取并消耗电力、是否允许或要求净现金结算、价格是否随某个市场变量变化、能否在市场中转售，以及会计准则如何判断。

### 一份合同可能出现在哪些地方

| 财报位置 | 可能出现的内容 | 初学者要问什么 |
| --- | --- | --- |
| 资产负债表 | 衍生品资产、衍生品负债、担保负债 | 这是已付现金，还是估值结果？ |
| 利润表 | 未实现公允价值损益、能源成本 | 是否影响当期利润？是否已有现金？ |
| 现金流量表 | 实际购电付款、保证金、终止付款 | 本期真正流出或流入多少现金？ |
| 承诺与或有事项附注 | 最低采购、未来付款、担保、终止费 | 表内余额之外还有多少长期责任？ |
| 衍生品附注 | 名义数量、期限、估值输入、NPNS | 为什么纳入或排除公允价值计量？ |

因此，合同没有完整出现在资产负债表上，不代表没有经济义务；资产负债表出现公允价值资产，也不代表已经收到同额现金。

### 什么是衍生品

Derivative 是衍生工具。入门上可理解为：合同价值会随电价、容量价格、利率、期限或其他基础变量变化，而且合同通常用较少初始净投入换取未来结算。

能源合同可能有两种主要结算路径：

```text
物理结算：实际取得并使用约定电力
净额结算：合同价格与市场价格差额用现金结算
```

Amazon 披露，部分合同在实际用电低于承诺数量时可能支付或收取净现金，因此被视为衍生工具。这个判断来自其具体合同，不能机械套用到所有 PPA。

### 什么是 NPNS

NPNS 是 Normal Purchases and Normal Sales，中文可理解为“正常采购和正常销售”例外。

如果企业签合同是为了满足可合理预期的正常经营需求，并预计实质接收和使用所承诺的商品，符合条件时可不按一般衍生品每期公允价值计量。

白话理解：

```text
为了实际经营而买电，且预计真的会用掉
-> 可能符合 NPNS

合同更像可净额结算的市场价格头寸
-> 更可能进入衍生品会计
```

NPNS 不是“公司自己想选就选”。企业需要满足条件、形成文件并持续判断；合同不再满足条件时，可能改为公允价值计量。

### 什么是公允价值和 Level 3

Fair Value 是公允价值，简化理解为在计量日市场参与者之间转让资产或负债的估计价格。它不是原始合同金额，也不是未来一定收到或支付的现金总额。

估值输入通常分层：

- Level 1：活跃市场中完全相同项目的报价；
- Level 2：可观察的相似报价、利率、远期曲线等；
- Level 3：重大输入不可直接观察，需要模型和管理层假设。

长期数据中心能源合同往往超过活跃远期市场的可观察期限，所以远端年份的电价、波动率和信用调整需要更多假设，可能成为 Level 3。

### 名义数量不等于公允价值

Notional Quantity 是名义数量，例如合同覆盖多少 MWh。它用来计算未来结算，但不是资产负债表价值。

```text
名义数量：合同覆盖的规模
合同价格：约定价格
市场远期价格：估值日对未来价格的判断
期限与折现：把未来差额折回今天
信用与履约风险：对收付可能性的调整
```

一个覆盖 1 亿 MWh 的合同，公允价值可能是正、负或接近零，取决于合同价格与市场曲线等因素。

### 未实现损益与现金流

Unrealized Gain/Loss 是未实现收益或损失。它表示估值变化已经进入会计利润，但合同尚未按对应金额现金结算。

例如：

```text
长期合同公允价值上升 5 亿元
-> 利润表可能确认未实现收益
-> 资产负债表增加衍生品资产
-> 本期经营现金流不一定增加 5 亿元
```

下一期市场曲线反向变化，未实现收益也可能回转。

### 担保、Backstop 和终止费

- Financial Guarantee：财务担保，承诺在特定违约或触发条件下付款。
- Backstop：兜底安排，在合作方不能履约或融资不足时提供支持。
- Termination Penalty：终止罚款或终止付款，提前退出合同时需承担的金额。

这些工具可以帮助能源或数据中心供应方获得融资，但也把交易对手风险和未来潜在付款留给担保方。

### 常见误区

- 误区一：合同名义数量就是资产价值。数量只是估值基础之一。
- 误区二：未实现收益等于现金收入。它可能只是模型估值变化。
- 误区三：NPNS 表示合同没有风险。它只影响会计处理，不消除价格、数量和履约风险。
- 误区四：表内没有负债就没有义务。最低采购、担保和终止费可能主要在附注。
- 误区五：Level 3 一定不可信。它表示重大输入不可观察，需要更仔细检查假设和敏感性。
- 误区六：所有 PPA 都采用相同会计。条款、监管批准、使用目的和净额结算能力不同。

## 第二大板块：实时背景与市场传导

### Amazon：长期电力合同怎样进入三张表

Amazon Q2 2026 10-Q 披露，公司签订能源合同以保障现有和未来运营的电力供应，部分期限可达 20 年。因运营变化导致用电低于承诺数量时，公司可能支付或收取净现金；Amazon 因此把相关合同作为衍生工具处理，并说明这些合同不在交易所或二级市场交易，也不用于投机。

截至 2026-06-30：

- 受衍生品公允价值计量的能源合同名义数量约 2.70 亿 MWh；
- 加权平均剩余期限约 15 年；
- 大多数电量将在未来九年之后交付；
- Q2 2026 确认未实现净收益 5.51 亿美元，2026 年上半年为 5.99 亿美元；
- 相关资产为 7.05 亿美元，相关负债为 1.33 亿美元。

这五组数字分别代表规模、时间、利润表估值和资产负债表余额，不能彼此替代。

### Amazon 的 Level 3 输入

Amazon 表示，估值会使用：

- 对未来约 4 至 6 年较有流动性的电力期货价格；
- 远期容量拍卖；
- 无风险利率；
- 更远期限的电价、隐含波动率和信用调整等管理层假设。

由于合同期限很长、远端市场数据不足，重大判断属于 Level 3。Amazon 同时明确，公允价值计量不会直接影响现金流，但可能对利润表和资产负债表产生重大影响。

### Amazon 的 NPNS 边界

公司表示，对于预计会实质消耗承诺电量的能源合同，符合条件时可能选择 NPNS。部分合同在取得监管批准前也暂不适用衍生品指引；若合同后来不再满足 NPNS，需要按公允价值计量并立即确认影响。

这形成一个复查触发器：

```text
实际用电计划下降或合同结算方式变化
-> 重新评估 NPNS
-> 可能转入公允价值计量
-> 利润表波动增加
```

### Alphabet：最低采购、担保与表外承诺

Alphabet Q2 2026 10-Q 披露，能源服务协议期限为 2 至 26 年，义务可延续至 2054 年，通常含最低能源数量的 take-or-pay 条款和实质性终止费用。

截至 2026-06-30：

- 长期供应、能源服务和内容许可等固定或保证承诺合计 7,070 亿美元，其中绝大多数与长期供应协议有关，并非全部是能源合同；
- 支持未来购电和能源协议长交付周期设备的财务担保，最大潜在付款为 76 亿美元；
- 信用衍生品形式 backstop 的最大潜在付款为 438 亿美元；
- 另有估计 241 亿美元的未来 backstop 安排支持数据中心和能源供应基础设施建设，条款尚待最终确定。

这里必须保持口径边界：7,070 亿美元是多个类别的合计承诺，不能写成“Alphabet 有 7,070 亿美元能源合同”。

### Microsoft：采购承诺不只看资产负债表

Microsoft FY2026 10-K 披露，截至 2026-06-30：

- 建设承诺为 345.66 亿美元，主要与数据中心有关；
- 采购承诺为 1,940.60 亿美元，主要与数据中心有关，包括未列入建设承诺的开放采购订单和 take-or-pay 合同；
- 未来 12 个月内到期的采购承诺为 1,690.08 亿美元；
- 租赁义务连同估算利息为 4,435.06 亿美元。

建设、采购和租赁承诺是不同类别，不能简单相加后称为当期 CapEx，也不能假设全部会在下一季度付现。

### 从合同到市场传导

```text
云厂商签长期能源与设备合同
-> 供应方获得融资和扩产确定性
-> 云厂商取得未来容量优先权
-> 最低采购和终止责任增加
-> 市场价格或需求变化引发公允价值与经济价值波动
-> 利润、现金流和回报周期可能不同步
```

## 政治、制度和规则视角

### 已确认事实

- Amazon 最新 10-Q 已明确披露能源衍生品、Level 3 估值、未实现损益和 NPNS 边界。
- Alphabet 最新 10-Q 已披露 take-or-pay、终止费、财务担保和 backstop。
- Microsoft 最新 10-K 已把建设承诺、采购承诺和租赁义务分开列示。

### 分析推理

- 数据中心争夺电力和设备，会推动云厂商用长期合同和担保换取供应确定性。
- 合同越长，可观察市场价格越少，估值对管理层假设越敏感。
- 大额承诺既可能支持未来增长，也可能在需求不及预期时形成固定成本和退出损失。

### 仍需观察

- Amazon 受公允价值计量的能源合同数量和 NPNS 适用范围是否变化。
- Alphabet 未来 backstop 条款何时最终确定，是否形成实际付款或资产。
- Microsoft 未来 12 个月采购承诺怎样转为 PPE、库存、应付账款和现金流。
- 电价、利率、信用风险和监管批准变化怎样影响估值。

## 关键词词典

| 关键词 | 中文翻译 | 白话解释 | 为什么重要 |
| --- | --- | --- | --- |
| Derivative | 衍生工具 | 价值随基础变量变化的合同 | 可能每期重估并影响利润 |
| NPNS | 正常采购和正常销售例外 | 为正常经营实际接收使用商品的合格合同可获例外 | 决定是否持续公允价值计量 |
| Fair Value | 公允价值 | 计量日市场参与者视角的估计价值 | 不等于合同总额或现金 |
| Level 3 | 第三级公允价值 | 重大估值输入不可直接观察 | 需要关注模型和假设 |
| Notional Quantity | 名义数量 | 用于计算结算的合同规模 | 不等于资产价值 |
| Unrealized Gain/Loss | 未实现损益 | 尚未完成现金结算的估值变化 | 利润与现金流可能背离 |
| Take-or-pay | 照提照付 | 未用够也需支付最低承诺量 | 带来数量和固定付款风险 |
| Financial Guarantee | 财务担保 | 特定违约时承担付款责任 | 可能形成或有义务 |
| Backstop | 兜底安排 | 在融资或履约不足时提供支持 | 把合作方风险转给担保方 |
| Termination Penalty | 终止付款 | 提前退出合同的成本 | 限制灵活性和退出能力 |

## 案例拆解

假设公司签订 15 年、1,000 万 MWh 的能源合同，本季模型显示衍生品公允价值增加 3 亿元，但没有对应现金结算。

1. 1,000 万 MWh 是名义数量还是公允价值？
2. 3 亿元应先理解为现金流还是未实现估值变化？
3. 如果公司预计不再实际消耗大部分电量，NPNS 是否需要重新评估？

参考思路：名义数量只描述规模；估值增加不自动产生现金；经营需求变化可能触发 NPNS 复查。

## 个人情境连接

- 对公司研究：看到“长期锁定能源”后，继续查结算方式、最低量、期限、估值层级和终止条款。
- 对基金研究：云厂商利润可能受非现金公允价值变动影响，需要与经营现金流对照。
- 对风险管理：把已付款、已确认负债、未实现估值和附注承诺分别记录。

## 结论边界

### 可以确定

- 长期能源合同可能同时影响承诺附注、资产负债表、利润表和未来现金流。
- 名义数量、公允价值、未实现损益和实际付款是四种不同概念。
- NPNS 影响会计计量方式，不会消除合同经济风险。

### 不能确定

- 不能仅凭公开摘要判断每一份能源合同的完整会计结论。
- 不能把 Alphabet 多类合计承诺全部归类为能源合同。
- 不能把 Amazon 未实现收益视为同额现金或持续经营利润。
- 本课不构成会计意见、法律意见或投资建议。
