## 第一大板块：理论基础

### 1. 公司融资与项目融资有什么不同？

Corporate Finance，公司融资，通常依赖母公司的整体资产负债表和经营现金流。Project Finance，项目融资，则尽量让贷款依赖某个项目未来产生的现金流，并以项目资产、合同和账户作为主要保障。

```text
公司融资：贷款人 → 母公司 → 多项业务共同还款
项目融资：贷款人 → 项目公司/SPV → 特定项目现金流还款
```

项目融资适合资本支出大、建设期长、合同现金流相对可识别的设施。它不会消除风险，只是重新规定谁先承担、谁可追索、资金怎样使用。

### 2. SPV：给项目装一个法律边界

SPV，Special Purpose Vehicle，特殊目的载体，是为持有特定项目资产、签订合同和借债而设立的独立法律实体。World Bank 项目融资资料指出，非追索融资通常由有限责任项目公司承接，贷款人主要依靠项目资产和现金流。[S1]

SPV 的作用包括：

- 把项目资产、收入和债务单独记录；
- 限制资金被挪到其他业务；
- 让贷款人对抵押物和账户获得明确权利；
- 便于设置项目级契约、储备账户和付款顺序。

SPV 不等于风险隔离绝对成功。母公司担保、交叉违约、控制权变化或欺诈等例外可能把风险重新带回母公司。

### 3. Recourse、Limited Recourse 和 Non-recourse

| 类型 | 贷款人主要可向谁追偿 | 白话理解 |
| --- | --- | --- |
| Recourse | 借款主体及担保母公司的广泛资产 | 项目不够还，可继续找担保方 |
| Limited Recourse | 特定情形可追索母公司或发起人 | 平时隔离，触发例外时穿透 |
| Non-recourse | 主要限于项目资产和现金流 | 原则上不能要求股东补足全部缺口 |

Non-recourse，非追索，不是“没人负责”。贷款人通常取得项目资产、股权、合同权利和受控账户的抵押，并设置严格契约。所谓 customary non-recourse carve-outs，是对欺诈、挪用抵押物、特定破产行为等例外保留追索。

### 4. Collateral：抵押品不只是一台服务器

Collateral，抵押品，是违约时贷款人可以依法处置或控制的资产与权利。项目融资的抵押包可能包括：

- GPU 服务器、网络和其他设备；
- SPV 的股权；
- 客户合同与应收账款；
- 银行账户、受限现金和保险权益；
- 租赁权益或其他项目权利。

抵押账面价值不等于回收价值。AI 设备会折旧、技术换代快，搬迁与再部署还需电力、网络、软件和客户，因此压力情景要对回收率打折。

### 5. DDTL：需要时分批提款

DDTL，Delayed Draw Term Loan，延迟提款定期贷款，是先承诺一笔额度，借款人在约定期间满足条件后分批提款。它适合设备按建设进度采购的项目。

需要区分：

- Commitment：贷款人承诺的最高额度；
- Drawn Amount：已经提取并开始计息的本金；
- Availability：尚可提款但可能受条件限制的额度；
- Undrawn Fee：未提款额度也可能收取的承诺费。

因此，“有 85 亿美元融资额度”不等于已经收到 85 亿现金，也不等于未来一定能全部提款。

### 6. Covenant：贷款合同里的护栏

Covenant，债务契约，是借款人必须遵守的财务或经营条件。常见内容有：

| 契约 | 目的 |
| --- | --- |
| 限制新增债务和留置权 | 防止其他债权人抢占偿付资源 |
| 限制分红、回购和投资 | 把现金优先留在项目 |
| 限制出售资产 | 保留抵押基础 |
| 维持 DSCR 或储备账户 | 提前发现偿债能力下降 |
| 强制对冲利率或电价 | 降低现金成本波动 |
| 重大合同持续有效 | 确保项目收入来源仍存在 |

违反契约不一定立即破产，可能先触发补救期、豁免谈判、限制分配或提前还款；要看合同原文。

### 7. Cash Waterfall：钱按顺序走

Cash Waterfall，现金瀑布，是项目收入进入受控账户后按优先级分配。

```text
客户现金收入
→ 必要运营与税费
→ 利息和计划本金
→ 补足债务服务储备账户
→ 维护性资本开支
→ 次级债务或其他受限付款
→ 满足契约后才可向股东分配
```

真实合同顺序可能不同。瀑布的意义是保护项目持续运营和优先债权人，不代表股东一定能收到最后一层现金。

## 第二大板块：实时背景与市场传导

### CoreWeave DDTL 4.0：非追索结构的真实样本

已确认事实：CoreWeave Q2 2026 10-Q 披露，其子公司 CCAC VIII 在 2026 年 3 月获得 85 亿美元 DDTL 4.0 额度，可在 2027-06-30前分批提款。截至 2026-06-30，已提取 14 亿美元浮动利率贷款和 15 亿美元固定利率贷款；贷款 2032 年 3 月到期，未提款部分年费率为 0.50%。[S2]

该贷款主要用于购买和安装计算基础设施，提款受合格资产采购价、设备折旧成本、预计偿债覆盖和项目条件约束。贷款以 CCAC VIII 股权和其几乎全部资产的第一顺位担保权益作保障；截至期末，相关抵押资产包括约 33 亿美元非流动资产和 1.55 亿美元流动资产。[S2]

公司把 DDTL 4.0 描述为非追索贷款，但同时存在惯常非追索例外的有限担保。契约还限制新增债务、分配、投资、留置权、资产出售、关联交易和重大重组。[S2]

分析推理：贷款人的核心保护不是母公司口头承诺，而是项目资产、提款条件、受限现金和契约。非追索减少常规情况下对母公司的追偿范围，却可能提高项目级控制强度。

### DDTL 5.5：同是项目融资，追索范围可能不同

已确认后续事项：CoreWeave 2026-08-07 8-K 披露，其间接子公司获得 26 亿美元 DDTL 5.5，主要为特定客户合同所需 GPU 服务器和基础设施资本开支融资。额度可在 2026 年 12 月承诺终止日前分批提款，2031-09-01到期。[S3]

该贷款按 Term SOFR 加 5.50%或替代基本利率加 4.50%计息，并收取未提款部分 0.50%年费。母公司为全部义务提供无条件担保，借款人子公司也提供担保，贷款以借款人及其子公司几乎全部资产和借款人股权作抵押。[S3]

分析推理：DDTL 4.0 与 5.5 都使用 SPV 和资产融资，但前者披露为非追索且有有限例外，后者有母公司无条件担保。不能只看到“DDTL”三个字就认为风险隔离相同。

### 项目融资怎样传导到业务和市场？

```text
客户合同更稳定
→ 贷款人愿意提高额度或降低利差
→ 数据中心更快采购设备
→ 容量上线支持收入
→ 项目现金流覆盖债务
```

反向路径也存在：客户合同延迟或取消，会削弱预计 DSCR、限制提款、推迟采购，甚至触发重新谈判。设备供应商收入、云厂商容量和贷款人风险因此相互连接。

### 流动性不等于现金

CoreWeave 10-Q 披露，截至 2026-06-30，总流动性为 155.53 亿美元，其中现金及现金等价物 55.24 亿、可交易证券 0.15 亿、现有融资安排可用额度 100.14 亿美元。[S2]

已确认事实与边界：可用额度属于流动性来源，但提款仍可能受资产、合同和其他条件限制。研究时应把“现金”“受限现金”“已提款债务”和“未提款额度”分栏，不能全部视为可以自由花费的现金。

## 政治、制度和规则视角

项目融资依赖公司法、担保法、破产法、抵押登记、能源许可和合同执行。相同的“非追索”标签在不同法域和合同中可能有不同例外。

World Bank 提醒，非追索项目融资让贷款人主要依赖 SPV 现金流与资产，因此贷款人需要对项目合同和现金流做严格尽调；项目过度依赖债务还会放大失败后的损失。[S1][S4]

SEC 文件中的 8-K 摘要并不替代完整信贷协议。CoreWeave 也明确说明 8-K 概述不完整，最终以附件中的完整合同为准。[S3] 学习者引用关键契约时，应区分公司摘要与合同原文。

## 关键词词典

| 关键词 | 中文与白话解释 | 用途 |
| --- | --- | --- |
| Project Finance | 项目融资；依靠特定项目现金流还款 | 隔离和分配项目风险 |
| SPV | 特殊目的载体；专门承接项目的法律实体 | 单独持有资产、合同和债务 |
| Recourse | 追索；可向母公司或担保方继续追偿 | 判断债务影响范围 |
| Non-recourse | 非追索；原则上主要限于项目资产和现金流 | 理解风险隔离边界 |
| Collateral | 抵押品；贷款人的担保资产和权利 | 决定违约回收基础 |
| DDTL | 延迟提款定期贷款；按进度分批提款 | 匹配建设付款节奏 |
| Covenant | 债务契约；借款人必须遵守的护栏 | 保护现金和抵押物 |
| Cash Waterfall | 现金瀑布；现金按优先级分配 | 判断谁先收到钱 |

## 案例拆解

### 示例：比较 DDTL 4.0 与 DDTL 5.5

| 维度 | DDTL 4.0 | DDTL 5.5 |
| --- | --- | --- |
| 承诺额度 | 85 亿美元 | 26 亿美元 |
| 到期 | 2032 年 3 月 | 2031-09-01 |
| 主要用途 | 合格计算基础设施 | 特定客户合同所需 GPU 与基础设施 |
| 追索 | 非追索，含有限例外 | 母公司无条件担保 |
| 抵押 | SPV 股权及几乎全部资产 | 借款人与子公司几乎全部资产及股权 |
| 关键复查 | 提款、项目交付、受限现金 | 浮动利率、DSCR、母公司担保 |

已确认事实来自 [S2][S3]。分析结论是：工具名称相同不代表贷款人权利和母公司风险相同。

## 个人情境连接

个人研究者看到“融资额度”时，应先问已经提取多少、是否受条件限制、利率和费用是多少、由谁担保。只比较额度大小会高估可用现金并低估固定费用。

持有数据中心或 AI 基础设施基金时，可在持仓表增加“追索范围、主要抵押物、浮动利率比例、客户合同依赖”四列，识别表面分散但共同依赖融资市场的风险。

## 结论边界

1. SPV 和非追索结构限制追偿范围，但不等于母公司完全无风险。
2. 承诺额度、已提款本金和现金余额是不同概念。
3. 抵押资产账面价值不等于违约回收价值。
4. 本课引用公开摘要，不能替代完整信贷协议和法律意见。
5. 项目融资分析是教学研究，不构成债券评级、贷款建议或证券买卖意见。
