# 第九十八课：云基础设施合同到现金流入门：RPO、递延收入、资本开支、折旧、自由现金流和估值边界

## 第一大板块：理论基础

### 1. 先问：客户付了钱，为什么还不算赚到了钱？

假设客户提前支付一年的云服务费。厂商账户里有了现金，但未来一年仍要提供服务、支付电费、维护设备。钱到账与完成服务不是同一天。

三张报表分别回答：

| 报表 | 回答的问题 | 云业务例子 |
| --- | --- | --- |
| 利润表 | 这一段时间完成多少服务、承担多少成本 | 履约收入、电费、折旧 |
| 资产负债表 | 某一天拥有什么、还欠什么 | 现金、服务器、应收账款、合同负债 |
| 现金流量表 | 这一段时间钱从哪里来、去了哪里 | 客户付款、买设备、借款和还款 |

第一步不是预测，而是给每一个数字贴上“余额或期间流量”的标签。

### 2. 五个容易混淆的金额

- 合同额：双方约定的交易规模，不一定全部满足会计上可计入剩余履约义务的条件。
- RPO，剩余履约义务：分配给尚未履行义务的交易价格。它可以含未来才开票的部分，不是银行存款。
- 合同负债：客户已支付或付款已到期，但企业尚欠交付的商品或服务。
- 收入：企业在满足履约义务时，按照适用规则确认的金额。
- 现金收款：客户实际支付的金额。已经确认的收入也可能暂时留在应收账款里。

若其他条件相同：先收款后服务产生合同负债；先服务后收款可能产生应收账款或合同资产。二者都不能只根据“签约时间”判断。

### 3. 不能默认把合同总额除以年数

合同要求持续提供随时可用的服务，且履约进度均匀时，按时间确认可能合适。若是按实际使用量履约，收入可能随着消费发生；软件许可、实施服务和算力也可能是不同履约义务。

IFRS 15 第 31、46 段的基础原则，是在履约义务满足时确认分配给它的交易价格。本课引用它解释一般原理，不把 IFRS 直接当成美国公司采用的会计准则；美国案例以各公司披露的美国 GAAP 政策为准。[S4]

第 97 课的三年合同案例已同步澄清：按期服务与按量消费必须分成两个明确情景，不能用 1,200 万美元收入推导只适用于 900 万美元收入的毛利。

### 4. 买设备为什么不等于马上花掉同额利润？

购买符合资本化条件的服务器，通常先形成固定资产；设备达到可供使用状态后，再按适用寿命分期确认折旧。付款、交付、达到可使用状态可能不在同一天，建造中的资产尤其如此。具体分类和折旧起点要读公司的会计政策。

```text
付款采购设备：现金下降，固定资产增加
后续折旧：利润下降，固定资产账面净值下降
当期折旧本身：不再发生第二次同额现金付款
```

折旧是资产成本的期间分摊，不是自动存入更新基金的一笔现金。把折旧加回经营现金流，只是在间接法下消除非现金费用，不意味着服务器没有经济成本。

### 5. 从利润桥接到现金

为便于入门，假设没有并购、汇率、税和其他复杂调整：

```text
经营现金流
≈ 净利润 + 折旧等非现金费用 - 非现金收益
  - 应收账款增加 - 存货增加
  + 经营应付款增加 + 已收款形成的合同负债净增加
```

真实公司要从现金流量表逐项核对；资产负债表的净变化不一定等于现金影响，例如收购、汇兑和重分类也会改变余额。资本性设备应付款不能直接当经营应付款加进这条简式。

自由现金流 FCF 的常见读法是经营现金流减现金资本开支，但公司定义可能不同。先照公司调节表复算，再做研究调整，不能把整个“投资活动现金流”当资本开支。[S5]

### 6. 为什么这会影响估值？

合同提升未来收入的可见度，现金流决定履约后能剩下多少资金。两者之间还隔着成本、资本开支、营运资本和履约期限。

```text
订单储备
 -> 实际交付和收入
 -> 利润及营运资本
 -> 经营现金流
 -> 再投资后的现金流
 -> 与风险和时间相匹配的估值
```

本课不把公司披露的 FCF 直接代入企业价值模型；现金流属于股东还是全部资本提供者、是否含利息与租赁，必须先统一。可回顾 DCF 与 WACC 基础课程。

## 第二大板块：实时背景与市场传导

### Microsoft：同一天的三个余额也不能直接相加

已确认事实：FY2026 10-K 的 Note 12 披露，截至 2026-06-30，未实现收入为 75,712 百万美元；全口径 RPO 为 684 十亿美元，商业部分为 678 十亿美元。未实现收入包含在 RPO 中，商业部分也不是全口径之外的新增金额。[S1]

分析推理：这是“集合包含关系”，不是三份独立的钱。把它们相加，会重复计算未来业务规模；把全部余额称为 Azure 合同，也会混淆业务范围。

仍需观察：未来确认时间、开票与回款、各产品履约方式以及新容量投入。余额增长本身不足以证明现金回报改善。

### Amazon：一张原始调节表直接解释现金缺口

已确认事实：截至 2026-06-30 的滚动十二个月，Amazon 合并经营现金流为 161,403 百万美元，扣除出售收入和激励后的物业设备购买为 169,007 百万美元；公司披露 FCF 为 -7,604 百万美元。[S2]

```text
161,403 - 169,007 = -7,604（百万美元）
```

这是集团合并口径，不是 AWS 单独自由现金流。现金资本开支超过经营现金创造能力，可以解释负 FCF；它既不能单独证明投资失败，也不能证明未来一定回本。

### Alphabet：需要分清半年度和滚动年度

已确认事实：Alphabet Q2 2026 10-Q 的现金流量表显示，2026 年上半年经营现金流为 84,859 百万美元，物业设备购买为 80,598 百万美元。[S3]

本课计算的简化现金差额是 4,261 百万美元；这是按上述两行相减得到的教学计算，不冒充公司另行定义的指标，也不代表 Google Cloud 单独现金流。

不能拿这项半年度差额与 Amazon 滚动十二个月数字直接排名。比较前，至少统一日期、期间长度、集团或分部范围以及资本开支定义。

### 市场传导的观察顺序

在其他条件不变的教学推理中，订单交付延迟可能使收入和回款推后，而设备采购或最低能源付款未必推后。现金缺口扩大可能增加融资需求；融资条件变化又会改变回报要求。实际股价反应还取决于此前预期，本课不预测方向。

## 政治、制度和规则视角

- 已确认事实：SEC 非 GAAP 指引 Question 102.07 明确指出 FCF 没有统一定义，需要清楚说明计算及调节，不能让人误以为它就是可任意支出的剩余现金。[S5]
- 分析推理：监管披露要求有助于让“利润好看”与“现金可用”分开核查；比较时应保留 GAAP 现金流原数，不只留下自定义指标。
- 仍需观察：公司是否改变指标定义、业务分部或合同确认政策。定义变化时要重做可比历史，而不是把断裂序列直接连起来。

## 关键词词典

| 关键词 | 中文翻译 | 白话解释 | 为什么重要 |
| --- | --- | --- | --- |
| Revenue Recognition | 收入确认 | 满足履约条件后把金额记成收入 | 不等于签约或收钱 |
| Contract Liability | 合同负债 | 收到或到期应收的钱对应尚欠的服务 | 解释预收款为什么不是利润 |
| Contract Asset | 合同资产 | 已交付但收款权仍有额外条件 | 与只等时间即可收取的应收款区分 |
| RPO | 剩余履约义务 | 合同中尚未履行部分对应的交易价格 | 观察未来业务而非现金余额 |
| Cash Conversion | 现金转化 | 收入和利润最终变成现金的过程 | 检查回款和营运资本 |
| Capex | 资本开支 | 为较长期使用的资产投入资源 | 区分付款与当期费用 |
| Capex Intensity | 资本开支强度 | 明确口径的资本开支除以同期收入 | 比较增长需要多少投资 |
| Depreciation | 折旧 | 分期分摊固定资产成本 | 利润费用不等于本期现金付款 |
| CFO | 经营活动现金流 | 日常经营实际带来的净现金 | 本课不是“首席财务官”的缩写用法 |
| FCF Conversion | 自由现金流转化率 | 例如 FCF/净利润，须声明分母 | 受非现金损益和投资周期影响 |
| Backlog Quality | 订单储备质量 | 已签业务转成有利润现金的可靠性 | 防止只比合同总额 |
| GAAP | 公认会计原则 | 公司采用的财务报告规则体系 | 自定义指标不能替代正式报表 |

## 案例拆解

以下为完全虚构、单位统一为万元的教学案例，不代表任何公司。期初只有现金 100、所有者权益 100，无负债。季度第一天收到全年不可退的固定服务费 12，服务义务为全年均匀提供可用容量；同日用现金 18 购买并立即启用设备，寿命三年、残值零、直线折旧。本季度现金运营成本 1.2，无税、融资、应收和其他费用。

| 事项 | 利润表 | 资产负债表 | 现金流量表 |
| --- | --- | --- | --- |
| 收到全年服务费 12 | 此时不确认收入 | 现金 +12，合同负债 +12 | 经营流入 +12 |
| 购置设备 18 | 此时不一次计入费用 | 现金 -18，固定资产 +18 | 投资流出 -18 |
| 本季度完成全年服务的 1/4 | 收入 +3 | 合同负债 -3 | 此时没有新收款 |
| 支付季度运营费 1.2 | 费用 +1.2 | 现金 -1.2 | 经营流出 -1.2 |
| 季度折旧 18/3/4 = 1.5 | 费用 +1.5 | 固定资产净值 -1.5 | 当期无第二次付款 |

```text
季度净利润 = 3 - 1.2 - 1.5 = 0.3
经营现金流（直接核对）= 12 - 1.2 = 10.8
经营现金流（间接核对）= 0.3 + 1.5 + 9 = 10.8
简化 FCF = 10.8 - 18 = -7.2
期末现金 = 100 - 7.2 = 92.8
期末资产 = 现金 92.8 + 设备净值 16.5 = 109.3
期末负债及权益 = 合同负债 9 + 权益 100.3 = 109.3
```

关键结论：本季度利润为正、经营现金流为正，但 FCF 为负；三者没有冲突。

第二季度若不再收预付款、不买新设备、继续同样服务和费用，利润仍为 0.3，经营现金流却为 -1.2。第一季度收到全年的钱，不等于每季度都有同样收款。仍未履约的部分不是可以无条件分配给股东的钱。

## 个人情境连接

- 接年度网站维护或视频制作订单时，预收款要与未来服务成本一起列预算，不能全部当本月可花收入。
- 研究云厂商时，分别记录合同余额、确认收入、收款与设备付款，不使用一个“大订单”数字代替四栏。
- 关注基金时，合并 FCF 不可随意分配给某个云业务，再据此计算该业务的估值。

## 结论边界

- 可以确定：合同、利润、现金是不同口径；教学例子三表平衡，真实公司调节数可回到原文件复算。
- 不能确定：未披露的客户级回款、项目 FCF、单份合同折扣和未来投资收益。
- 需要继续观察：预付款贡献是否重复、资本开支是否形成可售容量、合同履约是否延迟、现金流定义是否改变。
- 本课没有完整合同条款或项目级成本，不构成会计处理意见、估值结论或投资建议。
